# BugSwatter support

BugSwatter is a small open-source utility maintained on a best-effort basis.

Use [GitHub Discussions](https://github.com/mboler/BugSwatter/discussions) for setup questions, configuration ideas, and conversations that do not describe a reproducible defect. Use [GitHub Issues](https://github.com/mboler/BugSwatter/issues) for reproducible bugs and focused feature requests.

Before opening an issue, remove repository credentials, API keys, webhook secrets, internal hostnames, private IP addresses, absolute user paths, proprietary source, and complete model transcripts. A minimal sanitized configuration and the smallest relevant log excerpt are usually enough.

Potential vulnerabilities should not be filed as public issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
